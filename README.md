# Koridor Ortalama

EDS ortalama hız koridorlarında GPS ile canlı ortalama hızı, zaman payını ve mola kazancını gösteren web uygulaması (prototip).

- Kaynak 1: OpenStreetMap (`enforcement=average_speed`) – canlı çekilir
- Kaynak 2: elle yapıştırılan liste (ör. EGM haritasından)
- Telefona kurulabilir (PWA), Play Store için TWA'ya hazır

Ölçüm GPS'e dayanır, resmi ölçümle birebir aynı olmayabilir. Yasal limitler ve levhalar esastır.
